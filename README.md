## Password-generator


Password-generator is free and open-source gui password generation tool

---

## Features


* **Customizable Complexity:** Set custom lengths and toggle uppercase, lowercase, numbers, and special symbols.
* **Passphrase Generator:** Create readable, multi-word passphrases using an embedded wordlist.
* **Clipboard Integration:** Copy passwords directly to the Windows Clipboard via the Win32 API.


---

## Prerequisites

* **Visual Studio 2026** (or Visual Studio 2022)
* **Desktop development with C++** workload installed
* **Windows 10/11 SDK**

---

## Getting Started in Visual Studio

### 1. Clone & Open

1. Launch **Visual Studio**.
2. Click **Clone a repository** and enter `https://github.com/Jaiyuvan/Password-generator.git`.
3. Double-click `Password word.sln` in the Solution Explorer to open the solution.

### 2. Build & Run

1. Set your configuration to **Release** and **x64** in the top toolbar.
2. Build the project using `Ctrl + Shift + B` (or **Build > Build Solution**).
3. The generated executable will be saved in `\x64\Release\passgen.exe`.
